# Archivos de impresión de la base exhibidora

[English](README.md) · [Resumen del proyecto](../../README.es.md)

Accesorio opcional complementario: una base exhibidora de escritorio modular
para el datapad. Consulta la [sección de la base](../../docs/enclosure.es.md)
en la documentación de la carcasa para notas de ensamble y uso.

## Archivos

| Archivo | Tipo | Descripción |
| :--- | :--- | :--- |
| `StarWars_Stand_Base.stl` / `.step` | STL / STEP | Pieza de base con peso |
| `StarWars_Stand_Cradle.stl` / `.step` | STL / STEP | Cuna inclinada con el canal USB-C |
| `StarWars_Stand_Cradle_Multicolor.step` | STEP multicuerpo | Cuna con cuerpos sólidos separados para asignar colores en el slicer |
| `StarWars_Stand_Assembly.step` | STEP de ensamble | Conjunto completo de las dos piezas |

## Notas

- Ensamble de dos piezas por espiga y mortaja, sin herramientas — sin
  tornillos ni pegamento.
- La bahía inclinada sostiene el datapad en un ángulo de visualización de 70°.
- Un canal abierto continuo alineado con el puerto USB-C centrado permite
  cargar el datapad mientras está acoplado (cables rectos o en ángulo de 90°).
- Ambos STL también se publican como assets del
  [Release v1.0.0](https://github.com/AINxStep/star-wars-pocket-datapad/releases/tag/v1.0.0).
