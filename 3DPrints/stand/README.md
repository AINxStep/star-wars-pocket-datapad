# Desktop stand print files

[Español](README.es.md) · [Project overview](../../README.md)

Optional companion accessory: a modular desktop display stand for the
datapad. See the [stand section](../../docs/enclosure.md) of the enclosure
docs for assembly and usage notes.

## Files

| File | Type | Description |
| :--- | :--- | :--- |
| `ES3C28P_StarWars_Stand.3mf` | Bambu Studio project | Two plates: base + cradle, supports preconfigured |
| `StarWars_Stand_Base.stl` / `.step` | STL / STEP | Weighted base piece |
| `StarWars_Stand_Cradle.stl` / `.step` | STL / STEP | Inclined cradle with the USB-C channel |
| `StarWars_Stand_Cradle_Multicolor.step` | Multi-body STEP | Cradle with separated solid bodies for multi-color slicer assignment |
| `StarWars_Stand_Assembly.step` | Assembly STEP | Full two-piece assembly |

## Notes

- Both pieces **require supports** — the bundled `.3mf` already has them
  enabled with a dedicated support-interface filament.
- Two-piece, tool-free tenon/mortise assembly — no screws or glue needed.
- The inclined bay holds the datapad at a 70° viewing angle.
- A continuous open channel aligned with the centered USB-C port lets the
  datapad charge while docked (straight or right-angle cables).
- Both STLs are also published as Release assets in
  [Release v1.0.0](https://github.com/AINxStep/star-wars-pocket-datapad/releases/tag/v1.0.0).
- Ships as a second print profile on the datapad's
  [MakerWorld listing](https://makerworld.com/en/models/3460001).
